What Sentinel does

Sentinel is an end-to-end machine learning system for spotting fraudulent card payments. It covers the whole lifecycle of a model, not just the model itself.

Train and track

An XGBoost model is trained and every run is logged in MLflow with its metrics. The best version is registered as the production model.

Serve

A FastAPI service scores each transaction in milliseconds and saves every prediction to a database.

Monitor

Statistical tests compare live traffic with the training data to catch drift before accuracy drops.

Retrain

When drift crosses the threshold, a new model is trained, registered, and loaded into the running API.

The demo uses synthetic transactions. No real card data is stored or processed.

How to use this demo

Try the full monitoring loop in about two minutes.

  1. Pick a currency, then click Fill suspicious purchase and Score transaction. The needle moves toward red when the payment looks like fraud.
  2. Click Fill typical purchase and score it again to compare. Edit any field to see how the score changes.
  3. Click Send 100 normal transactions, then Check drift. The result should say there is no significant drift.
  4. Click Send 100 shifted transactions (larger amounts, farther from home, more activity), then Check drift. The shifted features turn red.
  5. Click Retrain model and enter the admin key. A new version replaces the old one. Retraining is protected, so on the public demo this step is for the owner.

Amounts in other currencies are converted to US dollars with approximate fixed rates before scoring, because the model was trained on dollar amounts.
